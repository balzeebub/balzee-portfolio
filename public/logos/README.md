# Client logos

Drop official brand assets here, then register them in `src/content/tools.ts`.

Expected filenames (any of these extensions):

- `exp-realty.svg`
- `pacific-realty-group.svg`
- `realty-of-america.svg`
- `everyday-order.png`

Prefer SVG. If only a raster asset exists, use a high-resolution PNG with a
transparent background (roughly 3x the display height, so ~96px tall minimum).

Do not redraw or recolour the artwork. Use the brand's own monochrome-white
version where one is published; otherwise use the official colour version.
